# Portfolio Hub

A Django-based portfolio management platform that allows developers and professionals to create, customize, and showcase their professional profiles, projects, and experience.

## Features

- **User Authentication**: Registration with email verification, secure login/logout
- **User Profiles**: Customizable profiles with:
  - Profile picture upload
  - Bio, title, and location
  - Social media links (GitHub, LinkedIn, Twitter)
  - Resume links
  
- **Portfolio Management**:
  - Add and manage multiple projects with descriptions and technologies used
  - Link to project repositories and live demos
  - Upload project images
  
- **Skills Tracking**: 
  - Add professional skills categorized as Frontend, Backend, Database, and Tools
  - Proficiency level indicators
  
- **Experience Logging**:
  - Track work experience with company, role, and dates
  - Add descriptions for each experience
  
- **Contact System**:
  - Contact form for visitors to reach out
  - Contact message management

## Tech Stack

- **Backend**: Django (Python)
- **Database**: SQLite (development)
- **Frontend**: HTML/CSS/JavaScript
- **Authentication**: Django built-in auth + Email verification

## Models

- **UserProfile**: Extended user profile with bio, location, social links
- **Skill**: Professional skills with categories and proficiency levels
- **Project**: Portfolio projects with descriptions and links
- **Experience**: Work experience and employment history
- **ContactMessage**: Messages from visitors

## Usage

1. **Register**: Create a new account and verify via email
2. **Complete Profile**: Add your profile picture, bio, and links
3. **Add Content**: Add your skills, projects, and experience
4. **Share**: Share your portfolio profile with others
